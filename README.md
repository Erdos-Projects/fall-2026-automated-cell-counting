## Ruiping RGB and grayscale experiment

Contributor: Ruiping Huang.

This personal branch contains a completed YOLO26n RGB/grayscale cell-counting comparison on the team's frozen 351/74/75 split. Test count MAE was 1.173 cells/image for RGB and 1.587 for grayscale in this single-seed experiment.
